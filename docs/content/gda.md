# GDA

The GDA backend shows backups and archives made with
[rclone gda backup](/commands/rclone_gda_backup/) as the files they
hold, reading only the CSV indexes GDA keeps in a hot storage class.
Nothing has to be restored to browse a backup, even one stored in S3
Glacier Deep Archive.

Point it at a remote holding GDA backups, for example:

```console
rclone lsf :gda:s3:lab-bucket/lab/results
rclone lsjson :gda:s3:lab-bucket/lab
```

Directories with a `gda-index.csv` are shown as the files they hold,
with their recorded sizes, modification times and MD5 hashes, and the
storage class of the object holding their data as their tier. Anything
else is shown as it is, so the backend can point at a GDA root or at
anything above it, such as a whole bucket.

Reading a file which is stored in a pack reads only that file's bytes.
Data in an archive storage class has to be restored first, with
[rclone gda restore](/commands/rclone_gda_restore/); until then reading
it gives the storage system's error.

The backend is read only. Symlinks and special files are listed in the
indexes but not shown, as they have no content to read.

To see a backup as it was at the end of an earlier run, set `at` to the
run ID or a time:

```console
rclone lsf ':gda,at="2026-09-01T00:00:00Z":s3:lab-bucket/lab'
```

A time has to be quoted in a connection string, as it contains `:`.

To see the objects GDA stores rather than the files they hold, set
`show_internals`.

## GDA commands

GDA backups are made and managed with the `rclone gda` commands:

- [rclone gda backup](/commands/rclone_gda_backup/) backs up a local
  directory tree, and [rclone gda plan](/commands/rclone_gda_plan/) and
  [rclone gda finish](/commands/rclone_gda_finish/) split a backup over
  several hosts.
- [rclone gda restore](/commands/rclone_gda_restore/) estimates the cost
  of a restore, requests archived data and fetches it, and
  [rclone gda prices](/commands/rclone_gda_prices/) refreshes the prices
  it uses.
- [rclone gda ls](/commands/rclone_gda_ls/) lists and
  [rclone gda find](/commands/rclone_gda_find/) searches a backup from
  its indexes.
- [rclone gda check](/commands/rclone_gda_check/) checks that a
  backup's data is all there, and can read back what is readable.
- [rclone gda gc](/commands/rclone_gda_gc/) reports on the stored data
  and removes objects left by runs that didn't finish.
